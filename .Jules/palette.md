## 2024-10-03 - Form Validation Accessibility & Micro-UX\n**Learning:** In simple vanilla HTML/JS single-page apps without formal component libraries, adding an `aria-invalid` state along with `aria-describedby` properly links error messages and communicates state visually (through CSS attribute selectors) and to screen readers simultaneously. Combining this with `focus()` ensures immediate keyboard correction flow.\n**Action:** Always pair `aria-invalid` toggling with `focus()` and `aria-describedby` when implementing manual validation in vanilla JS.
