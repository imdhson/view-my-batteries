# 🔋 view-my-batteries

같은 ID를 입력한 모든 기기의 배터리 잔량을 실시간으로 한 화면에서 볼 수 있는 작은 웹앱입니다. 별도 로그인이나 앱 설치 없이, 브라우저에서 같은 ID로 접속하기만 하면 됩니다.

## 특징

- **실시간 동기화** — Server-Sent Events(SSE)로 기기 상태가 바뀌는 즉시 모든 화면에 반영됩니다.
- **ID 기반 방(room)** — 별도 계정 없이 원하는 ID(영문/숫자/`-`/`_`, 1~64자)를 방 이름처럼 사용합니다.
- **자동 정리** — 30초 이상 응답이 없는 기기는 자동으로 목록에서 제거됩니다.
- **가벼운 서버** — 모든 상태는 메모리에만 저장되며, 외부 데이터베이스나 별도 프런트엔드 빌드 과정이 없습니다.
- **Liquid Glass UI** — 반투명 유리 질감의 카드, 은은하게 움직이는 배경 그라디언트, 상단 플로팅 바 등 최신 UX 패턴을 적용했습니다.

## 화면 구성 (디자인)

- **플로팅 바(Floating bar)**: 방 ID와 실시간 연결 상태, 나가기 버튼을 화면 상단에 떠 있는 캡슐형 유리 바에 배치했습니다. 스크롤해도 항상 화면 위에 고정됩니다.
- **Liquid Glass 카드**: 입장 화면과 기기별 카드에 `backdrop-filter` 블러와 하이라이트 테두리를 적용해, 뒤로 비치는 배경이 유리를 통과하는 듯한 질감을 줍니다.
- **라이트/다크 모드 자동 대응**: 시스템 색상 모드(`prefers-color-scheme`)에 따라 배경과 유리 톤이 자동으로 전환됩니다.
- **배터리 상태 시각화**: 잔량 퍼센트, 색상(초록/노랑/빨강)으로 구분되는 잔량 바, 충전 중 아이콘, 마지막 업데이트 시간을 카드에 표시합니다.

> ⚠️ 배터리 정보는 [Battery Status API](https://developer.mozilla.org/en-US/docs/Web/API/Battery_Status_API)를 사용합니다. Chrome/Edge(데스크톱·Android) 등 일부 브라우저에서만 지원되며, Safari·Firefox·iOS 계열 브라우저에서는 배터리 수치 대신 "지원하지 않음" 상태로 표시됩니다.

## 동작 방식

1. 브라우저가 ID를 입력해 방에 "입장"하면, 기기별 고유 ID(`localStorage`에 저장)로 자신을 등록합니다.
2. `Battery Status API`로 잔량/충전 여부를 읽어 `POST /api/battery`로 서버에 전송합니다. 값이 바뀌거나 10초마다 주기적으로 재전송합니다.
3. 같은 방을 보고 있는 모든 브라우저는 `GET /api/stream`(SSE)으로 연결되어, 방의 기기 목록이 바뀔 때마다 즉시 갱신된 목록을 받습니다.
4. 탭을 닫거나 "나가기"를 누르면 `POST /api/leave`로 기기를 방에서 제거합니다. 별도 종료 신호가 없어도 30초간 갱신이 없으면 서버가 자동으로 정리합니다.

## 로컬 실행

```bash
go run .
```

기본적으로 `:8080` 포트에서 실행됩니다. `ADDR` 환경 변수로 리스닝 주소를 바꿀 수 있습니다.

```bash
ADDR=:3000 go run .
```

브라우저에서 `http://localhost:8080` 을 열고, 같은 ID를 여러 탭/기기에서 입력해보면 실시간으로 동기화되는 것을 확인할 수 있습니다.

## 빌드

정적 파일(`static/`)은 `go:embed`로 바이너리에 포함되므로, 아래 명령 하나로 배포 가능한 단일 실행 파일을 만들 수 있습니다.

```bash
go build -o view-my-batteries .
```

## API

| Method | Path | 설명 |
| --- | --- | --- |
| `POST` | `/api/battery` | 기기의 배터리 상태를 등록/갱신합니다. |
| `POST` | `/api/leave` | 기기를 방에서 제거합니다. |
| `GET`  | `/api/stream?roomId=<id>` | 해당 방의 기기 목록 변경을 SSE로 구독합니다. |

모든 상태는 프로세스 메모리에만 존재하며, 서버를 재시작하면 초기화됩니다.

## 기술 스택

- 백엔드: Go (표준 라이브러리 `net/http`만 사용, 외부 의존성 없음)
- 프런트엔드: 순수 HTML/CSS/JavaScript (`static/index.html` 단일 파일, 빌드 과정 없음)
