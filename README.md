# 🔋 view-my-batteries

같은 ID를 입력한 모든 기기의 배터리 잔량을 실시간으로 한 화면에서 볼 수 있는 작은 웹앱입니다. 별도 로그인이나 앱 설치 없이, 브라우저에서 같은 ID로 접속하기만 하면 됩니다.

## 특징

- **실시간 동기화** — Server-Sent Events(SSE)로 기기 상태가 바뀌는 즉시 모든 화면에 반영됩니다.
- **ID 기반 방(room)** — 별도 계정 없이 원하는 ID(영문/숫자/`-`/`_`, 1~64자)를 방 이름처럼 사용합니다.
- **실시간 접속 상태** — 각 기기의 SSE 연결 자체를 접속 신호로 사용해, 탭을 닫거나 네트워크가 끊기는 즉시 "오프라인"으로 바뀝니다. 오프라인 기기는 "마지막 접속 n분 전"과 함께 10분간 표시된 뒤 자동으로 정리됩니다.
- **배터리 없는 기기 지원** — 데스크톱 PC처럼 배터리가 없거나 브라우저가 배터리 정보를 주지 않는 기기도 접속 여부와 함께 운영체제, 모델, 브라우저, 화면, CPU 코어, 메모리, 네트워크, 언어, 시간대, 탭 상태(보는 중/백그라운드) 등 수집 가능한 정보를 보여줍니다.
- **가벼운 서버** — 모든 상태는 메모리에만 저장되며, 외부 데이터베이스나 별도 프런트엔드 빌드 과정이 없습니다.
- **Liquid Glass UI** — 반투명 유리 질감의 카드, 은은하게 움직이는 배경 그라디언트, 상단 플로팅 바 등 최신 UX 패턴을 적용했습니다.

## 화면 구성 (디자인)

- **플로팅 바(Floating bar)**: 방 ID와 실시간 연결 상태, 나가기 버튼을 화면 상단에 떠 있는 캡슐형 유리 바에 배치했습니다. 스크롤해도 항상 화면 위에 고정됩니다.
- **Liquid Glass 카드**: 입장 화면과 기기별 카드에 `backdrop-filter` 블러와 하이라이트 테두리를 적용해, 뒤로 비치는 배경이 유리를 통과하는 듯한 질감을 줍니다.
- **라이트/다크 모드 자동 대응**: 시스템 색상 모드(`prefers-color-scheme`)에 따라 배경과 유리 톤이 자동으로 전환됩니다.
- **배터리 상태 시각화**: 잔량 퍼센트, 색상(초록/노랑/빨강)으로 구분되는 잔량 바, 충전 중 아이콘, 마지막 업데이트 시간을 카드에 표시합니다.
- **접속 상태 배지**: 카드마다 "실시간 연결됨 · 접속 n분째" 또는 "오프라인 · 마지막 접속 n분 전"을 표시하고, 오프라인 기기는 흐리게 보여줍니다.
- **기기 정보**: 배터리 정보가 없는 기기는 수집된 기기 정보를 카드에 바로 펼쳐 보여주고, 배터리가 있는 기기는 "기기 정보"를 눌러 펼칠 수 있습니다. 브라우저가 지원하지 않는 항목은 표시하지 않습니다.

> ⚠️ 배터리 정보는 [Battery Status API](https://developer.mozilla.org/en-US/docs/Web/API/Battery_Status_API)를 사용합니다. Chrome/Edge(데스크톱·Android) 등 일부 브라우저에서만 지원되며, Safari·Firefox·iOS 계열 브라우저나 배터리가 없는 기기에서는 배터리 수치 대신 접속 상태와 기타 기기 정보가 표시됩니다.

## 동작 방식

1. 브라우저가 ID를 입력해 방에 "입장"하면, 기기별 고유 ID(`localStorage`에 저장)로 자신을 등록합니다.
2. `Battery Status API`로 잔량/충전 여부를, 그 밖의 브라우저 API(`navigator.userAgentData`, `screen`, `hardwareConcurrency`, `deviceMemory`, `navigator.connection`, `Intl` 등)로 기기 정보를 읽어 `POST /api/battery`로 서버에 전송합니다. 값이 바뀌거나 탭 상태·네트워크가 바뀔 때, 그리고 10초마다 주기적으로 재전송합니다.
3. 같은 방을 보고 있는 모든 브라우저는 `GET /api/stream`(SSE)으로 연결되어, 방의 기기 목록이 바뀔 때마다 즉시 갱신된 목록을 받습니다. 이때 `deviceId`를 함께 넘기므로, 서버는 이 스트림이 열려 있는 동안 해당 기기를 "실시간 연결됨"으로, 닫히는 즉시 "오프라인"으로 표시합니다. (SSE가 막힌 환경에서는 최근 25초 내 갱신 여부로 대신 판단합니다.)
4. 탭을 닫으면 기기는 오프라인으로 바뀌고 10분 뒤 목록에서 정리됩니다. "나가기"를 누르면 `POST /api/leave`로 즉시 방에서 제거합니다.

## 로컬 실행

```bash
go run .
```

기본적으로 `:8080` 포트에서 실행됩니다. `ADDR` 환경 변수로 리스닝 주소를 바꿀 수 있습니다.

```bash
ADDR=:3000 go run .
```

브라우저에서 `http://localhost:8080` 을 열고, 같은 ID를 여러 탭/기기에서 입력해보면 실시간으로 동기화되는 것을 확인할 수 있습니다.

## 빌드

정적 파일(`static/`)은 `go:embed`로 바이너리에 포함되므로, 아래 명령 하나로 배포 가능한 단일 실행 파일을 만들 수 있습니다.

```bash
go build -o view-my-batteries .
```

## API

| Method | Path | 설명 |
| --- | --- | --- |
| `POST` | `/api/battery` | 기기의 배터리 상태와 기기 정보(`info`)를 등록/갱신합니다. |
| `POST` | `/api/leave` | 기기를 방에서 제거합니다. |
| `GET`  | `/api/stream?roomId=<id>&deviceId=<id>` | 해당 방의 기기 목록 변경을 SSE로 구독합니다. `deviceId`(선택)를 넘기면 이 연결이 해당 기기의 실시간 접속 신호가 됩니다. |

모든 상태는 프로세스 메모리에만 존재하며, 서버를 재시작하면 초기화됩니다.

## 기술 스택

- 백엔드: Go (표준 라이브러리 `net/http`만 사용, 외부 의존성 없음)
- 프런트엔드: 순수 HTML/CSS/JavaScript (`static/index.html` 단일 파일, 빌드 과정 없음)
